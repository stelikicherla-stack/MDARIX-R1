# MDARIX Design System

MDARIX uses a calm, evidence-oriented visual language: deep ink for hierarchy, teal for trusted action, warm amber for limitations, and generous white space for reviewability.

- Typography: system sans-serif; eyebrow labels are uppercase and tracked; headings use tight line height.
- Spacing: compact controls, 24px panel rhythm, generous public-page sections.
- Surfaces: white cards on soft blue-gray backgrounds; 1px borders; 12–16px radius; restrained shadows.
- Components: primary teal buttons, outlined secondary actions, labeled inputs, semantic sections, explicit status text.
- Accessibility: semantic headings, labels, keyboard focus outlines, visible errors/statuses, no color-only meaning, responsive layouts.
- Website/auth usage: public hero and cards use the same brand tokens as the authenticated application shell.
- Security language: avoid unsupported certification, confidence, or regulatory claims.
