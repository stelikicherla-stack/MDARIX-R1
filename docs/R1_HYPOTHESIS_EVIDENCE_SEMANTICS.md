# MDARIX R1 Hypothesis Evidence Semantics

Evidence relationships are explicit:

- `SUPPORTS`
- `CONTRADICTS`
- `CONTEXTUAL`
- `INSUFFICIENT`
- `UNRESOLVED`

Support is not proof.

Contradiction is not ignored.

Context is not support.

Missing information is not negative evidence.

Retrieval rank is not truth.

Graph path is not causality.
