# Platform Admin Dashboard Specification

The default administrator landing page is an operational dashboard, not an
invitation form. It presents Active Customers, Active Subscriptions, Licensed
Users, Customer Administrators, Active Connectors, Connector Issues, Mapping
Updates Pending, AI Executions Today, Security Alerts, and Pending Invitations.

The dashboard includes a Requires Attention panel and a Customer Health table.
Cards and rows link to the relevant scoped administrative view. Values are
server-derived; no customer complaint, investigation, evidence, CAPA, or
Decision Brief content is displayed.
