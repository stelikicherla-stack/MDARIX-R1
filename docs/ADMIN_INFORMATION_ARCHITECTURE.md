# Platform Admin Information Architecture

## Stage 1 navigation

- Overview: Dashboard
- Customers: Customers / Tenants, Create Customer, Customer 360,
  Customer Administrators, Invitations
- Plans & Subscriptions: reserved for Stage 2
- Identity & Access: Platform Users, Customer Admin Accounts, Memberships,
  Authentication, Sessions
- Integrations, Data Mapping, AI, Communications, Security, Platform, and
  Audit are grouped for later stages and remain permission-gated.

Every page has a page title, breadcrumb, authenticated administrator identity,
environment indicator, loading/empty/error states, and a visible primary action.
