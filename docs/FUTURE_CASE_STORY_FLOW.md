# Stage 3 Case Story Flow

Product → ProductVersion → Signal → Investigation → Evidence → Analysis → Hypotheses → Unknowns → Failure Chain → Scenario → Decision Brief → Human Decision → AI Assurance → Audit.

Every stage consumes the same server-validated Case Context. Missing prerequisites are shown as `REVIEW_REQUIRED`; no artificial confidence or causal conclusion is generated. Tenant and provenance boundaries are applied before a result reaches the UI.
