# MDARIX Connected Product Story

Stage 2 defines one governed narrative: Product → ProductVersion → change → complaint/signal → investigation → evidence → analysis → hypotheses/contradictions → unknowns → failure chain → risk → scenario → Decision Brief → human decision → assurance → audit.

The selected ProductVersion and temporal mode remain visible in every view. Each transition carries the same tenant and investigation context. Missing, contradictory, late, and unknown information is shown explicitly; the UI never converts absence of evidence into a conclusion.

## Acceptance

- Every story API is authenticated and tenant-scoped.
- AI output is advisory and marked for human review.
- Relationships are traceability links, not causal claims.
- Export and report actions preserve scope, provenance, limitations, and audit context.
