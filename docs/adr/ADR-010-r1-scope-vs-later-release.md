# ADR-010: R1 Scope vs Later Release

## Context
R1 is the first three-week working vertical slice. A later commercial release has broader scope.
## Decision
Use R1 terminology for this repository and exclude later commercial-release scope from Day 1 architecture freeze.
## Rationale
Clear terminology prevents roadmap contamination and uncontrolled scope expansion.
## Consequences
Day 1 documents R1 boundaries, exclusions, and Day 2 implementation contract only.
## Alternatives Considered
Mixing R1 with later commercial-release scope was rejected.
## Status
PROPOSED
