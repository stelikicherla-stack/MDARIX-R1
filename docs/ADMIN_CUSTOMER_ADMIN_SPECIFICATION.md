# Customer Administrator Specification

Creation uses First Name, Last Name, generated read-only Display Name, Email,
Customer, Administrative Role, and Status. There is no password field.

Management supports search by customer/name/email, resend invitation, password
reset initiation, deactivate/retire, reactivate, revoke sessions, email update,
and administrative audit. Passwords, hashes, tokens, and secrets are never
shown in the UI or written to ordinary audit details.
