# Dashboard Foundation

The dashboard family is Command Center, Product 360, Signals & Complaints, Investigation, Evidence, Decision, and AI Assurance. Backend analytics services own counts and aggregation; React is responsible for presentation and interaction only.

Persona emphasis is available through `/api/v1/analytics/persona/{persona}` for Investigator, Quality Manager, Regulatory, Risk Manager, Approver, and Executive. Persona changes emphasis, not tenant scope, authorization, or human authority.
